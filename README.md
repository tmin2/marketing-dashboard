# 📊 마케팅 통합 데이터 대시보드 프로그램

구글 스프레드시트([마케팅_통합대시보드](https://docs.google.com/spreadsheets/d/1r8g8NPEJmJxivwVRZ0KvnVBgv7_t5MdasyTL8XCVaAs/edit?usp=sharing)) 기반의 통합 마케팅 분석 및 엑셀 데이터 자동 연동 웹 대시보드 프로그램입니다.

---

## 🌟 주요 기능

1. **🏠 메인 통합 대시보드 & 엑셀 파일 업로더**
   - **스마트 파일 업로더**: 네이버, 쿠팡, 메타, 매출 엑셀(`xlsx`) 또는 `csv` 파일을 드래그하여 올리면 데이터베이스에 즉시 자동 반영됩니다.
   - **통합 엑셀 시트 자동 분기**: 하나의 엑셀 파일 안에 `DB_네이버`, `DB_쿠팡`, `DB_메타`, `DB_매출` 시트가 들어있는 경우, **자동 감지 모드**로 각 DB에 한 번에 나누어 저장합니다.
   - **핵심 KPI 요약 카드**: 총 광고비, 총 매출, 통합 ROAS, 통합 CPA, 통합 CTR, 통합 CVR 실시간 연동.
   - **기준 기간 필터링**: 기준 연도 및 기준 월(예: `2027-01`) 변경 시 모든 지표와 그래프가 동기화됩니다.
   - **인터랙티브 차트**: 월별 광고비 vs 매출 & ROAS 콤보 차트, 매체별 집행 비중 도넛 차트.
   - **채널별 성과 요약표 & 월별 추이 데이터 표**: 상세 지표 확인 및 비교.

2. **종류별 상세 분석 및 DB 관리 페이지**
   - 💚 **DB 네이버 광고 성과**: 마케팅 분류별(쇼핑검색, 플러스, 파워링크 등) 비중 및 전체 네이버 DB 조회/수정/저장
   - 🚀 **DB 쿠팡 광고 성과**: 월별 광고비/전환매출 추이, ROAS 추이 및 쿠팡 DB 조회/수정/저장
   - 🔵 **DB 메타 광고 성과**: 월별 광고 효율, 클릭/전환 추이 및 메타 DB 조회/수정/저장
   - 💰 **DB 전체 매출 성과**: 매출분류별(네이버, 쿠팡, 자사몰 등) 비중, 판매수량/배송건수 추이 및 매출 DB 조회/수정/저장

3. **📥 표준 엑셀 양식 제공**
   - 메뉴 내 `[엑셀 양식 다운로드 & 관리]`에서 통합 엑셀 양식 및 각 매체별 양식을 바로 다운로드할 수 있습니다.
   - 기존 데이터를 엑셀로 백업하거나, 초기 2027 샘플 데이터로 언제든지 복원할 수 있습니다.

## 🚀 실행 방법

### 방법 1. 윈도우 원클릭 실행 (가장 간편한 방법)
폴더 내의 **`run.bat`** 파일을 더블 클릭하시면 웹 브라우저(`http://localhost:8501`)에서 자동으로 대시보드가 열립니다.

### 방법 2. 터미널 명령어 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📁 프로젝트 구조

```
marketing_dashboard/
├── run.bat                     # 원클릭 실행 배치 파일
├── app.py                      # Streamlit 웹 대시보드 메인 프로그램
├── README.md                   # 프로그램 사용 설명서
├── data/                       # 데이터베이스 및 템플릿 저장소
│   ├── DB_네이버.csv           # 네이버 광고 실시간 데이터
│   ├── DB_쿠팡.csv             # 쿠팡 광고 실시간 데이터
│   ├── DB_메타.csv             # 메타 광고 실시간 데이터
│   ├── DB_매출.csv             # 전체 매출 실시간 데이터
│   └── templates/              # 다운로드용 엑셀 표준 템플릿
└── src/
    ├── __init__.py
    ├── data_manager.py         # 엑셀/CSV 파싱, 데이터 유효성 검사, 저장 모듈
    ├── metrics_calculator.py   # ROAS, CPA, CTR, CVR 등 KPI 계산 로직
    ├── visualizer.py           # Plotly 인터랙티브 그래프 생성 모듈
    └── generate_samples.py     # 초기 샘플 데이터 및 템플릿 생성기
```
